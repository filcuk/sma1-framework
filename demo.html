      def fibonacci(n: int) -> list[int]:
    """Return the Fibonacci sequence up to n terms."""
    if n <= 0:
        return []
    if n == 1:
        return [0]

    sequence = [0, 1]
    while len(sequence) < n:
        sequence.append(sequence[-1] + sequence[-2])
    return sequence

      What is this?

      This page is the component catalogue for SMA1 Framework — a vanilla HTML/CSS/JS kit for small static apps. Each section shows a reusable building block with the markup and behaviour.

      Use the page nav on the right to jump around, toggle sticky chrome under Theme → Options, and open this dialog from the tagline whenever you need a refresher.

      In short: this site is a living style guide. Scroll the demo sections to see each control, then copy the HTML and JS patterns into your own microapp fork. Nothing here needs a build step.
